01 · Comunidade e escolha — base implementada

Angular apresenta publicações, filtros, salvos e radar. A API controla autoria e permissões; PostgreSQL guarda os dados.

O usuário escolhe o que acompanhar. Não há nesta base um ranking de engajamento demonstrado.

Código da interface
02 · Curadoria humana — parcialmente atendida

O catálogo aceita apenas fontes aprovadas na configuração. Isso restringe a coleta, mas não comprova que uma avaliação editorial humana ocorreu.

Próximo passo: publicar critérios, justificativas, responsáveis e datas de revisão; permitir sugestões e correções. Fontes de qualidade podem errar.

Regras atuais
03 · Coleta e radar privado — implementado, desativado por padrão

Escolha de 1–3 fontes, palavras e exclusões; frequência de 6/12/24h; até 20 itens por rodada. Resultados privados, pausa e exportação.

RSS/Atom transporta conteúdo; filtros por palavras não entendem significado nem validam fatos. O catálogo inicial está vazio.

Contrato da API
04 · Histórias e perspectivas — branches separadas

Há trabalho em agrupamento, comparação simulada e quotas nas branches avançadas. Não está integrado a esta candidata de entrega.

Comparar versões exige fontes identificadas e evidências. Concordância não equivale a verdade; IA não substitui revisão humana.

05 · Roteiro → HyperFrames → vídeo — demonstração local

JSON demonstrativo validado gera composição HTML editável. Um vídeo de 26s Full HD foi renderizado localmente. Não é ainda geração automática de notícias auditadas.

Execução e limites
06 · Testes e entrega — CI aprovada, revisão visual pendente

Testes de backend, frontend e API com PostgreSQL descartável passaram no GitHub. O vídeo possui testes de conteúdo inválido e proteção contra sobrescrita.

Faltam inspeção visual completa, catálogo editorial real e conciliação das branches. A main não foi alterada.
